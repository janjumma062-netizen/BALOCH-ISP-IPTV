# BALOCH ISP IPTV Mobile App - Setup Guide

## Quick Start

```bash
# Install dependencies
npm install

# Start the app
npm start

# Run on Android
npm run android

# Run on iOS
npm run ios
```

## Project Structure

```
mobile/
├── App.tsx                    # Main navigation
├── src/
│   ├── screens/              # App screens
│   └── utils/                # Helper functions
├── android/                  # Android build
├── ios/                      # iOS build
└── package.json
```
